# Personal Portfolio - FrontEnd Developer

## Features
- **Professional Introduction**: Learn about my background and skills as a frontend developer.
- **Contact Section**: Easily get in touch with me via the contact form or my social media links.
- **Skillset** : use animation for skillset showcase. 
- **Responsive Design**: The portfolio adapts to different screen sizes for an optimal viewing experience on any device.

## Technologies Used
- **HTML5**: For structuring content.
- **CSS3**/**Scss**: For styling and ensuring a responsive design.
- **JavaScript**: For interactive elements.
- **React**: To build reusable components and manage state .
- **Vercel**: For deployment and hosting.
